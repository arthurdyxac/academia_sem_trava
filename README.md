# Academia Sem Trava

Página oficial de vendas do protocolo Academia Sem Trava, da Dyxac Labs.

## Publicar no GitHub e na Vercel

1. Envie `index.html`, `vercel.json`, `.gitignore` e a pasta `assets` para a raiz do repositório.
2. Na Vercel, importe esse repositório do GitHub.
3. Mantenha **Framework Preset** como `Other`.
4. Não preencha comando de build.
5. Mantenha a pasta de saída como a raiz do projeto e clique em **Deploy**.

O checkout utilizado pela página é `https://pay.kiwify.com.br/SLXqsH2`.
